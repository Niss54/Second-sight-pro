# Medical Voice Assistant

This module is the lightweight voice layer for SecondSight Pro.

## What it keeps
- speech-to-text compatible request flow
- text-to-speech ready responses
- real-time friendly short outputs
- interruption-friendly segmentation

## What it removes
- conferencing
- video
- unrelated streaming extras
- generic demo agents

## Public APIs

```ts
import { speakMedicalSummary, askFollowupQuestion } from "./modules/medical-voice-assistant";
```

## Output characteristics
- calm
- empathetic
- medically responsible
- short enough to read aloud

## Notes
The module is designed to plug into SecondSight Pro and to work with LiveKit-based real-time delivery or text fallback delivery.
